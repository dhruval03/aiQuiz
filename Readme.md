# AI Quizzer Microservice

An intelligent quiz microservice powered by AI that allows students to attempt quizzes, get evaluated, retry, view their history, receive hints, and get personalized improvement suggestions via email.

---

## ✨ Features

* ✅ **JWT-based Authentication** (Mock login for first-time users, secure login afterwards)
* ✅ **AI-Powered Quiz Generation** based on grade, subject, difficulty
* ✅ **Quiz Submission** with partial scoring support for multiple correct answers
* ✅ **Quiz Retry Support**
* ✅ **Hints for Questions** (AI-generated)
* ✅ **Email Notifications** on submission (with two AI-generated skill improvement suggestions)
* ✅ **Quiz History & Filtering** by grade, subject, date range, and score

---

## 🧰 Tech Stack

* **Node.js** + **Express.js**
* **Prisma ORM** + **PostgreSQL**
* **Zod** for validation
* **OpenAI/Groq AI** for content generation
* **Nodemailer** for email

## 📁 API Endpoints Summary

| Endpoint                             | Method | Description                                           |
| ------------------------------------ | ------ | ----------------------------------------------------- |
| `/api/auth/login`                    | `POST` | Mock login for first-time, validates on repeat logins |
| `/api/quiz/generate`                 | `POST` | Generate new quiz (AI)                                |
| `/api/quiz/submit`                   | `POST` | Submit quiz responses                                 |
| `/api/quiz/retry`                    | `POST` | Retry quiz with new responses                         |
| `/api/quiz/history`                  | `GET`  | Fetch quiz history (with filters)                     |
| `/api/quiz/:quizId/hint/:questionId` | `GET`  | Get AI-powered hint                                   |

---

## 🧠 AI Prompts & Logic

* AI generates quizzes based on subject, grade, difficulty
* Questions may have one or more correct answers
* Partial score is awarded for partial correct responses
* Hints and improvement suggestions are generated by AI
* Suggestions sent via email after each submission
